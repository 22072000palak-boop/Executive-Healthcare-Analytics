# Executive Healthcare & Financial Analytics Dashboard

## 📌 Project Overview
An interactive executive dashboard built using Tableau Public to analyze patient volume, financial metrics, medical condition distribution, and insurance provider billing.

---

## 📊 Key Metrics & Insights
- **Total Patients:** 40,235
- **Total Billing Amount:** $1,417,432,043 ($1.41B)
- **Top Medical Conditions:** Arthritis, Diabetes, Hypertension, Cancer, Obesity, and Asthma.
- **Insurance Breakdown:** Distribution across UnitedHealthcare, Medicare, Cigna, Aetna, and Blue Cross.
